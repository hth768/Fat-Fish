## 修复：合并判断引入的 `NameError: name 'Dict' is not defined`
- 根因：上一步合并编辑在 `_judge_capabilities` 的返回注解 `-> Dict[str, object]` 与模块级 `_FEATURE_ISSUE_COOLDOWN: Dict[str, float] = {}` 用了 `Dict`，但 chat_service.py **未 `import Dict`、也无 `from __future__ import annotations`**，且无未来注解时函数定义/模块注解在导入期即求值 → 导入即崩。
- 表现：用户发"你能帮我设置定时任务吗？"→ 控制台回"出错了：name 'Dict' is not defined"。旧进程靠陈旧 .pyc 仍能服务，故误以为能跑；py_compile 只查语法不执行注解，漏报。
- 修复：在 docstring 后、`import asyncio` 前加 `from __future__ import annotations`（注解延迟求值，修复且不改运行期语义）。
