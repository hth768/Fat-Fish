# 状态机（Routine 模式库）框架 — LLM 可调用 + 观察自动推荐 + 优雅暂停

## 核心设计
- **新文件 `F:\qq_bot\mc_routines.py`**：声明式状态机框架 + 7 个内置模式。不 import 大脑模块，通过注入的 `actor` 接口（BotAgent 适配）驱动，纯逻辑可单测。
- **运行模型**：大脑把 `routine {name, args}` 当一个普通工具调用执行（复用现有 exec 循环/遥测/防重试）。routine 内部逐步走状态机：每步通过 actor 调现有工具（dig_target/craft/place/chest/furnace/goto…），**步骤幂等**（每步先查背包/环境再动手）→ 天然支持"重跑即续跑"。
- **触发**：①LLM 显式调 routine 工具；②观察里按背包/场景自动推荐一行"可用模式"。
- **暂停（用户选的优雅暂停）**：routine 运行中玩家说话 → 不再粗暴 cancel：设 pause 标记，routine 在**当前小步完成后**干净收尾（停移动/关窗口）→ 返回 `fail:paused-<name>:进度…（想继续就再调用同名 routine 自动续跑）` → 大脑回应玩家并可决定 resume（重调）/放弃。普通动作仍按现在的立即打断。
- **安全自中止**：routine 每步/每 4 秒查 /state：血量≤6/饥饿≤6/空气低/近岩浆 → 立即中止并返回原因，交给大脑守卫处理。每模式有步数与时间预算（默认 240s）。

## 7 个内置模式（全部幂等，逻辑基于背包/环境推导进度）
1. `gear_up` 升装备：木工具→挖 8 圆石→石镐→熔炉→（背包有 iron_ore 则烧锭）——中间缺什么就现场补（合成/放工作台自动找空格）
2. `smelt_ores` 自动烧矿：把背包 iron/copper/gold ore 全烧（自动备熔炉、燃料 oak_log/coal，轮询成品）
3. `gather {material: wood|stone, n}` 采集：自动换斧/镐→scan 找目标→逐块挖到 n（换目标不硬磕）
4. `store_all` 物资入库：非工具/食物/建材类全部 chest store（背包清爽）
5. `go_home {name=家}`：查 mc_explored 地标坐标 → goto 回家
6. `escort_owner` 跟随主人：每 5 秒看主人坐标→保持 4~8 格（主人离线/超时自动结束）
7. `explore_new_area` 探索新区：mc_explored 挑未探方向→走 40 格→环视记录→回报发现

## 验证
1. 单测（假 actor）：gear_up 材料齐全/缺料两分支、gather 目标数、暂停语义、安全中止触发
2. 实机：大脑跑起来后从 dashboard 写提示"把背包里的矿石烧掉"→ 观察它调 smelt_ores、遥测出现 routine 事件、中途在游戏里说话→ 确认暂停返回 & 再喊继续能续跑
3. 主人实测口头指令："升级一下装备/把东西放箱子里/跟着我/回家"

## 不做
战斗自动巡逻、建筑放置规划、模式持久化到磁盘（重启后由 LLM 重新触发）、守卫自动拉起模式（本次仍只有溺水强制反射；致命场景由 routine 自中止+守卫接管）。
