# 2026-09-15

## 新增：UI 外观自定义（主题色 + 窗口标题）
用户希望能在 UI 内改变界面颜色主题与窗口标题。

实现：
- `bridge/appearance.py`：外观设置模块。8 套主题（midnight/aurora/forest/rose/sunset/ocean/crimson + light 浅色），
  每套由 CSS 变量整盘定义；标题持久化到 `data/appearance.json`（最长 40 字）。
  API：`get_appearance(theme=None)`、`save(theme,title)`、`get_window_title()`。
- `server.py`：新增 `GET /api/appearance`（支持 `?theme=` 实时预览变量）与 `POST /api/appearance`（保存）。
- `bridge/app_window.py`：新增 `_AppearanceApi.set_title`，注入 pywebview `js_api` 实现窗口标题栏实时改名；
  启动窗口时由 `app.py` 读取已存标题作为 `WINDOW_TITLE`。
- 前端 `webui/index.html`：侧栏新增「外观」导航项 + 外观页（主题色卡网格 / 标题输入框 + 恢复默认）。
  `webui/app.js`：`loadAppearance()` 启动即应用并存主题；色卡点击即时预览；保存后写回并调用 `window.pywebview.api.set_title`。
  `webui/styles.css`：新增 `.theme-grid/.theme-swatch` 样式，品牌图标改用 `var(--accent)` 随主题变色。

标题作用于：窗口标题栏（pywebview 模式实时 / 其他模式重启生效）、侧栏品牌名、浏览器标签。

## 追加：背景图设置
外观页新增「背景图」面板：
- 支持本地上传（PNG/JPG/GIF/WEBP，≤8MB，base64 经 POST /api/appearance 的 `bg_data` 字段，存为 `data/appearance_bg`）或填远程 http(s) 链接（`bg` 字段）。
- `GET /api/appearance/bg` 以原始字节回传本地背景图（按魔数判定 content-type）；`_serve_raw` 新增于 server.py。
- 前端 `applyBg(bg)`：bg="local"→`/api/appearance/bg`，否则用链接；`body` 设 background + `#bgDim` 固定暗化遮罩（z-index:-1，opacity .82）保证文字可读。
- 校验：非 http(s) 链接 / 超限图片 → ValueError，由 POST 错误响应抛出，前端 toast 提示。
