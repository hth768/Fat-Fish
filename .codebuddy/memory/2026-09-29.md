### 关键坑（Node 侧，都踩过）
1. `--import` 在 Windows 只认 `file://` URL（`Path.as_uri()`）；**入口脚本**反而要用普通路径，
   传 file:// URL 会被 Node 当相对说明符解析。
2. 模块定制钩子**必须 `register()` 注册**，只在 --import 的模块里 export `resolve` 不生效。
3. 必须同时导出 `resolve` 与 `resolveSync`：tsx 解析 .ts 里的导入走**同步链**，只给异步钩子会漏。
   （Cortico 自己的 tsconfig 有 `paths: {"cortico/*": ["./src/*"]}`，tsx 也能靠它解析。）
4. 子进程 cwd 要设在能解析到 tsx 的目录（用 `CORTICO_NODE_CWD`，默认 `CORTICO_CORE_ROOT`）。
5. 装配层 bug：`defaults()` 里的 enabled 被预置的 False 挡住 → 改成对齐 Cortico 的 `{…defaults(), enabled: declared}`。
